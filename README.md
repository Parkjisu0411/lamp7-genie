# LAMP7 Genie

LAMP7의 **화면 설계(Visual editor)**와 **이벤트/트랜잭션 설정(Logic)**에서 검색·다중선택·삭제·복사·붙여넣기를 돕는 Chrome 확장 프로그램입니다. 두 편집 화면에서만 패널을 열 수 있습니다.

## 설치 가이드

배포 압축 파일을 받은 경우 압축을 해제한 뒤 2번부터 진행합니다.

1. 소스로 설치하는 경우 의존성을 설치하고 빌드합니다.

   ```bash
   npm install
   npm run build
   ```

2. Chrome에서 `chrome://extensions`를 엽니다.
3. 오른쪽 상단의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 클릭합니다.
5. 프로젝트 또는 배포 파일의 `dist` 폴더를 선택합니다.
6. LAMP7의 화면 설계 또는 이벤트/트랜잭션 설정에서 확장 프로그램 아이콘을 클릭합니다.

업데이트할 때는 확장 프로그램 관리 화면에서 확장을 새로고침하고, LAMP7의 작업 내용을 저장한 뒤 페이지를 새로고침하세요.

## 공통 사용법

**검색**으로 항목을 찾고, **편집 → 선택 시작**으로 여러 항목을 고릅니다. 선택모드는 LAMP7 기본 조작과 구분됩니다.

- 선택모드에서는 큰 패널 대신 이동 가능한 보라색 조작 바가 나타납니다. 바에서 **복사·삭제·종료**를 실행할 수 있습니다.
- 클릭으로 선택·해제하고, 마우스 드래그로 범위를 선택합니다. 편집 영역 바깥은 흐리게 표시되며, 바깥에서도 드래그를 시작할 수 있습니다.
- 선택 목록을 펼쳐 개별 항목의 **×**로 해제하거나 전체 해제할 수 있습니다.
- 선택·복사 목록은 유형·라벨·ID를 한 줄로 표시합니다. 라벨이 없으면 ID를 이름 자리에 한 번만 표시합니다.
- 기본 패널의 복사 목록은 같은 자리에서 접고 펼칩니다. 별도 목록을 중복으로 띄우지 않습니다.
- **종료**하거나 복사·붙여넣기가 완료되면 기본 패널로 돌아갑니다. 선택 중에도 **패널 열기**로 목록을 확인할 수 있습니다.
- 붙여넣는 동안 조작 바에 처리 상태를 표시합니다. 화면 설계는 완료한 묶음 수, 로직은 생성·연결 처리 상태를 표시합니다.
- 복사한 항목은 다른 화면·다른 Chrome 탭에서도 붙여넣을 수 있습니다. 화면 설계와 로직의 복사 데이터는 각각 보관합니다.

드래그 선택 기준은 편집 대상에 따라 다릅니다.

| 대상 | 선택 기준 |
| --- | --- |
| 화면 설계 | 드래그 영역 안에 완전히 들어온 컴포넌트 |
| 로직 | 드래그 영역에 일부라도 겹친 로직 |

## 화면 설계 검색·편집

### 검색

현재 화면의 eID·vID·DOM ID, 라벨·텍스트를 검색합니다. **ID / 이름·텍스트** 필터를 사용할 수 있습니다.

- 결과에는 컴포넌트 유형·라벨·ID와 설명이 있는 경우 설명을 표시합니다.
- 결과를 선택하면 해당 위치로 스크롤하고 주황색 테두리로 표시합니다.
- Input·Button 등에 연결된 라벨은 본체와 중복 표시하지 않습니다.
- 같은 Grid 열의 Col과 Cell이 함께 검색되면 **Col 하나**로 표시합니다. Cell만 검색되면 반복된 Cell을 **하나로 묶어** 표시합니다. 실제 검색된 위치는 모두 유지하며, 서로 다른 Grid나 열은 구분합니다.
- 숨김 항목과 비활성 탭 내부도 검색하며, **현재 숨김** 상태를 표시합니다. 검색 때문에 항목을 자동으로 펼치지는 않습니다.
- 구성요소가 변경되면 결과를 갱신합니다.

검색은 LAMP7의 기본 선택이나 저장할 HTML·설정을 변경하지 않습니다.

![화면 설계 검색 데모](./assets/demo-visual-search.gif)

### 선택 단위

클릭으로 선택·해제하고, 드래그 영역에 완전히 들어온 컴포넌트를 선택합니다. 캔버스 바깥에서도 드래그를 시작할 수 있어 가로를 채운 Row·Grid도 선택할 수 있습니다.

부모와 자식이 함께 범위에 들어오면 **가장 상위 컴포넌트만 선택**합니다. 예를 들어 `Row > Col > Input` 전체를 감싸면 Row 하나를 선택하며, 숨김 자식도 함께 포함합니다. 선택 목록에는 숨김 항목이 있을 때만 숨김 표시를 붙입니다.

| 컴포넌트 | 선택 단위 |
| --- | --- |
| Grid | Grid 전체. Col·머리글·Cell은 개별 선택 불가 |
| Cascader | 본체 전체. 내부 입력부·목록·노드는 개별 선택 불가 |
| Tree / Manual Tree | 트리 전체. 개별 노드는 선택 불가 |
| 기간 입력 | From / To를 포함한 본체 |
| DataSelect / InputGroup | 내부 버튼을 포함한 본체 |
| Radio / Checkbox | 옵션을 포함한 본체 |
| Dropdown | 내부 구조를 포함한 본체 |
| 페이징·페이지 정보·페이지 크기·Grid 연결 버튼/도구 | 직접 선택 제외 |

내부 항목을 클릭하면 선택 가능한 본체를 선택합니다. 범위 선택은 본체 전체를 감싸야 하며, Grid의 일부 열·셀만 감싸면 선택되지 않습니다. 선택된 부모의 선택 가능한 하위 항목을 클릭하면 부모 전체를 해제합니다.

선택모드에서는 기본 이동·속성 편집·단축키를 차단하며 휠 스크롤은 사용할 수 있습니다. 탭 전환이나 화면 구성 변경 시에는 선택모드를 정리합니다. Cascader·Tab 등 세부 기준은 [개발 참고](docs/development.md)를 참고하세요.

### 삭제

**삭제**를 누르면 별도 미리보기·확인창 없이 선택한 본체를 순서대로 삭제합니다. LAMP7 기본 삭제 경로를 사용하여 하위·연관 항목과 설정을 정리합니다.

삭제 중에는 중복 실행을 차단하고, 앞선 삭제로 이미 사라진 항목은 건너뜁니다. 오류나 취소가 발생하면 중단하고 실제 삭제 개수와 남은 선택을 표시합니다.

### 복사·붙여넣기

1. 선택모드에서 항목을 고르고 **복사**를 누릅니다. 하위·숨김 항목까지 보관하고 기본 패널로 돌아갑니다.
2. 같은 화면 또는 다른 화면·탭에서 **붙여넣기**를 누릅니다.
3. 마우스로 원하는 위치를 가리킵니다. LAMP7의 기본 배치 규칙에 따라 컨테이너 안·컴포넌트 앞뒤·최상위 위치에 삽입 표시가 나타납니다.
4. 위치를 클릭하면 붙여넣고 선택모드를 종료합니다. **취소** 또는 `Escape`로 위치 선택을 취소할 수 있습니다.

복사 범위와 배치 규칙은 다음과 같습니다.

- **ID:** 사용자 항목 ID(`eid`)는 기존 값을 유지하고, 충돌하면 LAMP7 기본 채번을 사용합니다. DOM ID(`id`)와 설정 키(`vid`)는 새로 생성하며, 내부 연결과 Grid 반복 항목의 설정 공유는 유지합니다.
- **포함 데이터:** 라벨·하위 구조·항목별 스타일·설정·업로드 이미지 데이터를 포함합니다.
- **항목 간 연결:** 함께 복사한 항목끼리의 연결은 유지하고, 복사 범위 밖 항목과의 연결은 제거합니다.
- **제외 데이터:** 관련 이벤트·로직 정의와 실행 연결은 복사하지 않습니다. 외부 참조 제거로 유효하지 않게 된 조건·계산식은 해당 설정을 해제합니다.
- **배치:** 원래 부모 종류가 달라도 기본 배치 규칙이 허용하면 붙여넣을 수 있습니다. 필요한 Row·Col은 LAMP7 기본 방식으로 생성합니다.
- **여러 항목:** 모두 들어갈 수 있는 공통 위치가 있어야 합니다. 허용되지 않은 묶음을 일부만 삽입하지 않습니다.
- **테이블 연결:** 대상 화면에 테이블·열이 있으면 연결을 유지합니다. 없으면 해당 연결만 해제하고 컴포넌트는 붙여넣습니다. 테이블을 자동으로 가져오지는 않습니다.

원본 탭을 닫아도 복사 데이터를 사용할 수 있으며 다른 탭의 복사 목록도 갱신됩니다. 이전 버전의 복사 데이터에 배치 정보가 없으면 원본에서 다시 복사해야 합니다.

## 로직 검색·편집

### 검색

생성된 코드의 변수명이나 호출 메소드 등으로 해당 로직 위치를 찾습니다.

- 로직 Prefix: 예) `logic18038`
- Event / Transaction / Variable ID
- Transaction 호출 메소드명
- Condition / Parameter 값

![로직 검색 데모](./assets/demo-logic-search.gif)

### 선택·삭제·복사

**선택 시작** 후 클릭 또는 드래그로 로직을 고르고 **삭제**나 **복사**를 실행합니다.

선택된 로직 위에는 라벨을 가리지 않도록 **순번만** 표시합니다. 선택·복사 목록에는 로직 유형 아이콘과 **원본 전체 로직에서의 순번**을 표시합니다. 이 번호는 선택한 순서나 복사 목록의 순서가 아닙니다.

변수 로직을 복사하면 직접 참조하는 **일반 지역변수 정의**도 함께 보관합니다. 붙여넣는 화면에 해당 변수가 없으면 추가하고, 같은 ID의 자료형·구조·초기화 설정이 같으면 기존 변수를 사용합니다. 정의가 다르면 LAMP7 기본 채번으로 ID 뒤에 숫자를 붙여 새 변수를 만들고, 붙여넣는 로직의 지역변수 참조도 새 ID로 연결합니다. 기존 변수와 기존 로직은 변경하지 않습니다.

전역변수·입력 파라미터·반복문의 임시변수는 자동 추가하지 않습니다. SAP 자동 생성 변수는 지원하지 않습니다. 지역변수 정보를 포함하려면 업데이트 후 로직을 다시 복사하세요.

![로직 편집 데모](./assets/demo-logic-edit.gif)

### 위치 선택 붙여넣기

1. 로직을 복사하고 대상 화면에서 **붙여넣기**를 누릅니다.
2. 마우스를 움직여 삽입 위치 표시를 확인합니다.
3. 원하는 위치를 클릭하면 붙여넣고 기본 패널로 돌아갑니다.

| 위치 | 붙여넣기 동작 |
| --- | --- |
| 조건·반복 로직 제목 안쪽 | 해당 로직의 하위 끝에 추가 |
| 로직 제목 아래쪽 경계 | 같은 단계의 다음 위치에 추가 |
| 편집 영역 맨 위·아래 빈 공간 | 최상위 시작·끝에 추가 |
| 빈 편집 화면 | 첫 로직으로 추가 |

부모·순서·트랜잭션 연결은 LAMP7 기본 LogicEditor를 통해 갱신하며, 영향을 받는 기존 로직도 다시 검증합니다. 편집 중인 로직이 있으면 기본 완료 처리를 먼저 실행하며, 검증에 실패하거나 편집이 끝나지 않으면 붙여넣기를 중단합니다.

위치 선택은 **취소** 또는 `Escape`로 취소할 수 있습니다.

## 단축키

| 조작 | 동작 |
| --- | --- |
| 확장 프로그램 아이콘 클릭 | 패널 열기 / 닫기 |
| `Alt + Shift + F` | 패널을 열고 검색창에 포커스 |
| 검색창에서 `Enter` | 검색 실행 또는 다음 결과로 이동 |
| 검색창에서 `Shift + Enter` | 이전 결과로 이동 |
| 패널에서 `Escape` | 패널 닫기 |
| 선택 영역에서 `Escape` | 선택모드 종료 또는 붙여넣기 위치 선택 취소 |

Chrome 단축키가 충돌하면 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.

## 주의사항

LAMP7 공식 기능이 아닌 개인 제작 보조 도구입니다. LAMP7 버전이나 화면 구조에 따라 동작이 달라질 수 있습니다.

- 자동 저장과 별도 묶음 Undo는 제공하지 않습니다. 기본 Undo가 설정·이벤트까지 일괄 복구하는 것은 보장하지 않습니다.
- 화면 설계의 항목별 스타일과 클래스 이름은 보관하지만, 별도 전역 CSS·외부 스타일시트는 복제하지 않습니다.
- 붙여넣기 도중 오류가 발생하면 실제 생성 개수를 표시하고 중단합니다. 통신이 끊긴 작업은 자동 재시도하지 않습니다.
- 로직 복사·붙여넣기 후에는 생성된 소스를 확인하세요. 내부 데이터 차이로 소스 생성 오류가 발생하면 수정이 필요할 수 있습니다.
- 실제 LAMP7에서의 저장 후 재열기·소스 생성·Undo/Redo 검증은 남아 있습니다. 자세한 검증 범위는 아래 개발 문서를 참고하세요.
